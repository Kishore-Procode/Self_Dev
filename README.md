# ASTRA Asset Pack

Frontend asset pack for the ASTRA goal-training app.

## Contents
- `assets/branding/` — ASTRA logo and app mark
- `assets/icons/` — lightweight inline-ready SVG icons
- `assets/backgrounds/` — dark/red UI backgrounds
- `assets/reference/` — optional visual reference

## Intended stack
HTML5 + CSS3 + Vanilla JavaScript only.

## Usage
SVGs can be used directly with `<img src="...">` or in CSS.
For a single-file prototype, keep these assets in the `assets/` directory.

## Design tokens
Primary: black / charcoal
Accent: crimson red
Secondary: gold
Success: restrained clover green
Text: warm white
